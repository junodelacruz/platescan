# Platescan

Platescan is a personal calorie tracking and nutritional app. Take a picture of a plate of food, and recieve an AI estimated breakdown of the calories and macros. Log plates, track weight, and view progress!

## Overview

Platescan is a browser based web app built with Expo and React Native Web on the frontend, and Node + SQLite for the backend. It is containerized as its own Docker instance and hosted entirely on my home server. With DuckDNS + NGINX Proxy Manager, it can be accessed as any regular website.

The app is built around a simple concept: reduce the time and effort it takes to track calories. Now you may ask, why didn't I just use an already existing app? I tried, yet all the apps I came across had the scan feature locked behind paywalls. Of course I was unwilling to pay if I had the means to create it myself for free. And so, this led me down a rabbit hole that eventually ended with me running a local AI model on my machine to assist me in creating Platescan. Platescan was created with the use of agentic AI assisted software engineering to help me embark on my fitness and physical health journey. I am a computer science student at NJIT with no patience to track calories by hand, so I created it as my own personal free alternative to scanning plates, hence the name Platescan.
